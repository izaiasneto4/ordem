What it does

  

    
01sync

    
Pulls every open PR that's waiting on you through gh. No tokens to paste, no GitHub app to install.

    
02review

    
Checks out the head in a git worktree and runs your agent with the whole repo as context. --type swarm splits it across security, correctness, performance and API reviewers.

    
03decide

    
Findings land pre-checked with a suggested verdict. Drop the noise with X, keep the rest.

    
04submit

    
One review goes to GitHub as you, with inline comments on the right lines. ⌘↵ and on to the next PR.

Questions

  

    
Does my code leave my machine?
Only as far as your agent sends it. Ordem has no backend. It runs the CLIs you already use with the credentials you already have.

    
Will it post to GitHub on its own?
No. Every review waits in your inbox until you submit it, and you choose which findings go with it.

    
Which models does it use?
Whatever your agent CLI is set to. Switch per review between Claude, Codex and OpenCode, or set a default in settings.

    
Is it free?
Yes, MIT licensed. You pay for your agent's usage, same as you do today.
