02Workflow

A mail client for pull requests. Triage, delegate, decide.

Every PR is a thread and the agent is a collaborator inside it. Ordem tracks where each one is, so the only question left is what needs you next.

Ordem shells out to gh, git and your agent. Your code stays in a worktree on your disk, and your state lives in one SQLite file.
